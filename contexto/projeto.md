## O que é este projeto
Mineral LP — Landing Page oficial e plataforma comercial de Engenharia de Infraestrutura para Recarga Rápida de Veículos Elétricos (Parceiro Homologado WEG). Desenvolvido em Next.js 16 (App Router), React 19, Tailwind CSS v4, Lucide Icons e formulário de viabilidade de engenharia CapEx.

## Stack e tecnologias
- Framework: Next.js 16 (App Router, React 19, TypeScript)
- Estilização: Tailwind CSS v4 com paleta institucional Mineral (--color-mineral-orange #F1713C, --color-mineral-yellow #FBCB2A, --color-mineral-blue #035085)
- Ícones: Lucide React
- Deploy: Vercel

## Estrutura de pastas relevantes
- `src/app`: Rotas e layout Next.js (layout.tsx, page.tsx, globals.css)
- `src/components`: Componentes da Landing Page (HeroSection, MarketOpportunity, ROIMatrix, TurnkeyProcess, LeadForm, FAQ, Footer, Navbar)
- `src/fonts`: Arquivos de fontes locais (Kabrio, LemonMilk)
